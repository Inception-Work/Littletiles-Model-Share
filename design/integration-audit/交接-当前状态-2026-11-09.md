## 4. 最近一次修改：个人空间看不到私有作品（2026-11-08，仅 1.12.2）

- **现象**：我的空间/个人空间只列公开作品，私有（private）与凭码（unlisted）作品与合集不出现。
- **根因**：`GuiMySpace` 复用了公开作者页接口 `GET /api/v2/authors/{id}/works`，该接口按设计只返回 public。
- **修法**：新增 `ApiClient.myWorks()`，改走认证接口 `GET /api/v2/studio/library?page=&size=100&locale=`，所有者由会话决定（不传 `authorId`，防越权），循环拉全分页合并后交给原 GUI 本地分页；超过 100 页报 `V2_LIBRARY_TOO_LARGE`。配套 `V2Contract.libraryPath()`、`Dtos.WorkCard.visibility`、`ApiContractChecks` 3 条断言。
- **后端**：`/opt/inception-work-v2/releases/20261108-owner-submit/server.jar`（SHA-256 `ad02850e4951c1121ad5351644fda3bbb89c3b5724b77e6d8879fff8e007be0e`）已上线；公开作者页仍只返回 public；他人/匿名不能借此读私有详情或下载。
- **验证**（据 `lts-112/design/integration/本人作品库-2026-11-08.md`）：后端 12/12、前端 59/59、真实 Chrome 6/6、模组离线 build + API 契约 83 项 + 七语言 + OBJ 检查通过。
- **未覆盖**：该修复**只存在于 1.12.2 工作树**。其余 5 个平台的 `GuiMySpace` 仍调用 `authorHome()`，线上仍然缺私有作品；预览 jar 也已不在 `output/mod-owner-library/`。
