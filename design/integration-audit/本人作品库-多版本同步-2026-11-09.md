## 图片验收反馈与补充修复

用户验收 Forge 1.20.1 反馈：图片没有加载，预览和下载正常。实查六版 ImageCache 都未向资源请求传入 token。实际使用本机现有会话和客户端 V2Transport 只读验证：私有作品 509 的封面匿名请求 HTTP 404，认证请求 HTTP 200 且 ImageIO 解码成功；公开作品 296、206 的图片在匿名和认证时都返回 HTTP 200 并解码成功。只读取现有库与图片，未创建测试数据，未记录任何凭据。

六版补充图片认证；凭据仍由现有传输层限定到同源 /api/v2/，重定向到 CDN 或直接访问第三方图片时不发送 Bearer。图片成功/失败缓存按站点和 token 隔离，会话变更清理旧纹理，丢弃旧会话异步结果，允许新会话重试。

五个现代版增加私有图片认证、匿名拒绝、CDN 重定向与直接第三方图片凭据隔离四项回归检查，检查数从 18 增至 22。Forge 1.12.2 保持既有 V2Http 同源认证和重定向检查，修复 ImageCache 调用处传入 token。

图片修复构建日志：各工作树 owner-library-image-build.log。五个现代版均 build + V2 检查 22 项通过；Forge 1.12.2 build、83 项 API 契约、七语言和 OBJ 检查通过。

## 登录凭据失效处理与重新验收

用户要求统一修复登录凭据失效时自动检测并进入登录界面的行为，并从头测试。

六版新增共享 SessionRequests 恢复策略：打开面板时检查 /auth/me；同源 API 的 HTTP 401 先尝试续期并只重试一次。无刷新凭据、刷新明确被服务器拒绝（400/401/403/410）、或重试仍返回 401 时清空失效双令牌，由渲染线程打开 GuiLogin。网络或 5xx 故障、权限 403、资源 404、第三方/CDN 的拒绝不当作账号过期。图片、蓝图、OBJ 和上传也使用会话恢复流程；登录/刷新请求本身不触发递归续期。

旧请求不能清除期间更换的新账号或新站点。登录窗口不重复嵌套；只有用户仍在本模组界面时才自动打开登录页，离开模组后不抢占其它界面。取消登录后可返回，不自动反复重开。PAT 保存后也会检查有效性。

新增 SessionChecks 20 项；首版 Forge 1.20.1 最终构建已通过 20 项会话检查及 22 项 V2 检查。其它版本的最终构建依次运行，日志 owner-session-build.log。前两轮产物哈希为历史记录，已被本轮会话修复产物取代。

重新验收从 Forge 1.20.1 开始，之前的用户结果不代表这轮已通过。操作约束（用户明确纠正）：当前窗口保持运行，必须等用户明确确认可以关闭/切换后才操作；若修复需要重启，同样先等用户同意。曾在未等确认时关闭客户端，已恢复 Forge 1.20.1。
