**LittleTiles Model Share 1.0.0**

- 公开作品支持免登录浏览与下载；上传、我的空间、收藏及关注等账户功能才要求登录 INC 账号。
- 新增独立 Grid 循环筛选：所有 Grid 与 LittleTiles 当前配置支持的全部档位，包括配置允许的 64、128；可与游戏版本、作者和标签组合使用。
- 混合 Grid 合集只要包含符合条件的作品就会显示；进入合集后只展示所选 Grid 的条目。
- 领取蓝图前检查当前 LittleTiles 支持的网格和结构内的实际 Grid，包含子结构，修复不兼容蓝图领取后手持崩溃的问题。
- 关注动态接入完整关注列表，按作品发布时间展示并分页；底部按钮只翻动态，上方固定展示最近更新的作者，“更多”使用独立分页。
- 进入世界后检查模组更新，稳定版与测试版分别检查对应渠道；支持当前语言的更新说明、换行与滚动，以及前往下载、稍后提醒和永不提醒。
- 优化未登录提示与公开作者主页访问，避免浏览公开内容时被要求登录。
- 配套网站修复模组访问令牌默认权限，新增令牌可正常用于浏览、上传、保存和下载作品。
- 1.20.1 专项：封面和头像改用 CDN 缩略图，增加图片并发，减少原图传输与整页等待。
- 修复选择作者后标签、加载器及游戏版本条件被忽略的问题
