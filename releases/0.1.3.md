# LittleTiles Model Share 0.1.3 测试版

加入更多游戏内浏览与分享体验：

- 多语言：支持简体中文、繁体中文、英语、日语、韩语、德语和法语，跟随游戏语言切换；作品与标签显示网站提供的对应译文。
- 模型预览：在支持预览的作品详情中，直接查看模型，拖动旋转、滚轮缩放。
- 作者主页：点击作品详情中的作者头像或名字，浏览作者介绍与作品，还能搜索和翻页；从作者页进入作品后，再点作者即可返回原作者页。
- 浏览布局：作品列表随窗口大小显示更多内容，标题更加紧凑。
- 逐级返回：返回按钮统一位于右下角，按 ESC 逐层返回，查看预览时先退出预览。
- 邀请作品：通过作品编号和访问码进入邀请作品详情。

适用于 Minecraft 1.12.2，需要安装 Forge、LittleTiles 和 CreativeCore。更新时请替换旧版模组；联机时客户端与服务端使用相同版本。
