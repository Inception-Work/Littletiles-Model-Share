# LittleTiles Model Share 0.1.4 测试版

加入收藏、关注与个人空间：

- 收藏与关注：从模型列表底部进入，收藏页分「单个作品 / 合集」，关注页展示关注的作者与他们的最新作品。
- 我的空间：查看自己发布的作品和合集。
- 快捷操作：作品详情可直接收藏，作者主页可直接关注。
- 预览增强：放宽白模大小限制，塔吊等大型作品更容易在游戏内查看。
- 上传改进：自动带上来源版本；可选择公开或私有；默认语言跟随账号设置，未设置时使用游戏语言。
- 搜索与浏览：高级搜索会记住上次作者搜索并保留结果，再次点击已选作者可取消；分页更简洁，不再显示作品总数。

适用于 Minecraft 1.12.2，需要安装 Forge、LittleTiles 和 CreativeCore。更新时请替换旧版模组；联机时客户端与服务端使用相同版本。
