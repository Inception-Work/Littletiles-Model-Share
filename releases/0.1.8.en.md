**LittleTiles Model Share 0.1.8**

**What's changed**

- This release adapts the mod to the website's rebuilt infrastructure. The site was reworked for stronger security, better reliability and easier long-term maintenance, and the mod now talks to it correctly again.
- Nothing changed in the mod itself: browsing, downloading, uploading and submitting all work exactly as before.
- If you were seeing empty model lists, covers that never loaded, or sign-in errors, this build fixes those.

**How to update**

Remove the old mod jar from your `mods` folder, then drop the new one in its place. On a server, the client and the server should run the same version.
